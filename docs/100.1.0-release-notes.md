## Feature
- Added the "Search for logo" option. When enabled, the enricher searches Google Images for logos instead of any image.
- The enricher now returns up to 10 clues per search, each with its own image, instead of a single clue.
- Added a `Logo` vocabulary key (Google Images vocabulary) holding the URL of each image. It can be mapped to the Preview Image of the golden record.

## Fixes
- Skip candidate images that cannot be downloaded, so no clue is produced without an image.
- Skip images that cannot be used as a Preview Image in mapping (only .jpg, .jpeg, .gif and .png links are returned as clues).
- Generate the clue entity code from the image URL, so each image gets a distinct and stable code.
